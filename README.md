# Chai-n-Code JavaScript Notes

This repository contains JavaScript practice files and notes organized by topic. It follows a lesson-style structure, starting from JavaScript basics and moving into arrays, objects, functions, control flow, and loops.

## Topics Covered

- JavaScript variables and data types
- Type conversion and operations
- Strings, numbers, maths, and dates
- Arrays and array methods
- Objects
- Functions, scope, closures, hoisting, and arrow functions
- Control flow using conditions and switch statements
- Loops and iteration methods such as `for`, `while`, `for...of`, `for...in`, `forEach`, `filter`, and `map`

## Folder Structure

```text
Chai-n-Code/
├── 01_basics/              # Variables, data types, strings, numbers, dates
├── 02_basics/              # Arrays and objects
├── 03_basics/              # Functions, scope, arrow functions, closures
├── 4.control_flow/         # If/else, switch, truthy/falsy values
├── 5.loops__iterartions/   # Loops and array iteration methods
└── 6.six.js/               # Additional lesson folder
```

## How To Run

Make sure Node.js is installed, then run any JavaScript file from the terminal:

```bash
node 01_basics/01_variable.js
```

For files inside folders with spaces or special characters, wrap the path in quotes:

```bash
node "5.loops__iterartions/10_map_method.js"
```
